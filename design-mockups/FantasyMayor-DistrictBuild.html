FantasyMayor — Забудова району

Модель без карток. Люди = робітники (1 одиниця = 1 людина, Anno-style). У v1 — один тип, селяни; типи/раси (ремісники, майстри, ельфи, орки) як дерево — потім. Будівництво = AP + ресурси + селяни, триває N ходів; Платник = Власник (Мер/Місто). Район дає дії з фіксованим кроком: дія = (селяни + AP [+ вхідні ресурси]) → фіксований вихід (split City/Owner/Operator), вихід може бути дробовим (до десятих); max worker capacity = скільки таких наказів влазить на тайл. Натисни «+ Збудувати район».
USS-faithful: усе всередині панелей тримається в межах UI Toolkit — flexbox, суцільні кольори, відступи через margin (без gap), без тіней / блюру / градієнтів / grid. Зелений світ за панелями — це рендер сцени (камера), не UI Toolkit.
